# مرحله صفر — خط مبنا و حفاظت از سامانه موجود

## وضعیت
- ممیزی تکمیلی Floot در 2026-11-12 انجام شده است.
- Typecheck پاک گزارش شده است.
- 11 فایل آزمون در نوبت اخیر موفق بوده‌اند.
- هیچ migration، حذف داده، تغییر secret یا انتشار Production انجام نشده است.
- این مخزن GitHub تازه ایجاد شده و در شروع، خالی بوده است.

## یافته‌های قابل اتکا درباره Floot
- پروژه فعلی Floot با React/TypeScript و backend serverless TypeScript کار می‌کند.
- پایگاه داده PostgreSQL دارد.
- وجود منو یا صفحه به معنی تکمیل عملیاتی ماژول نیست.
- در ممیزی داده‌ای پیشین: 46 جدول عمومی، 3 شرکت، 78 حساب و 5 سند حسابداری دیده شده بود.
- داده عملیاتی انبار/تولید در بررسی قبلی مشاهده نشده بود.
- مواردی مانند استفاده از JS Number برای پول، انتخاب شرکت ناامن در برخی endpointها و ابهام idempotency در بعضی مسیرها نیازمند اصلاح طراحی هستند.

## حفاظت
1. Floot تا زمان تصویب برنامه مهاجرت، مرجع موجود باقی می‌ماند.
2. هیچ داده، جدول، endpoint، secret یا تنظیم اتصال حذف یا overwrite نمی‌شود.
3. هر انتقال فقط پس از backup قابل بازیابی، آزمون restore و تطبیق شمارش/جمع‌ها مجاز است.
4. قرارداد APIهای مصرف‌شده حفظ می‌شود تا ممیزی تمام مصرف‌کننده‌ها تکمیل شود.
5. هر تغییر دارای checkpoint، commit و گزارش آزمون خواهد بود.
