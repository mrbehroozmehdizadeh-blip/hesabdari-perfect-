# قواعد هسته دفترکل — نسخه اولیه دامنه

## قواعد قطعی پیاده‌سازی
1. مبلغ با decimal نگهداری می‌شود؛ float و double برای مبلغ ممنوع‌اند.
2. ارز هر مبلغ صریح است و جمع ارزهای متفاوت بدون تبدیل ثبت‌شده ممنوع است.
3. هر ردیف سند یا بدهکار است یا بستانکار؛ ثبت همزمان هر دو در یک ردیف ممنوع است.
4. سند حداقل دو ردیف دارد.
5. جمع بدهکار و بستانکار باید دقیقاً برابر باشد.
6. جمع سند باید مثبت باشد.
7. این مدل فقط اعتبارسنجی دامنه است؛ هنوز ذخیره‌سازی، شماره‌گذاری، مجوز، گردش تأیید، idempotency و ثبت قطعی دفترکل پیاده‌سازی نشده‌اند.

## مرز ایمنی
این مدل هیچ سندی را به وضعیت Posted نمی‌برد. ثبت قطعی بعداً باید از مسیر مجوز، اعتبارسنجی حساب و دوره مالی، کنترل tenant، تراکنش اتمیک، قفل/کنترل همزمانی و audit trail عبور کند.
